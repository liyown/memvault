# 界面改版 · 2026-10-15（第二轮）

上一轮只修整控件，整体仍像堆砌：圆角十种取值、导航与内容同色、本地状态在四处重复、按钮层级混用、路径只能手输。本轮按 design/DESIGN.md 重建设计系统和页面结构。

## 结构

- 两层表面：导航在画布上，工作区是带阴影的浮起纸面。去掉页脚、面包屑和侧栏口号；侧栏底部只保留记忆位置与刷新。
- 会话、记忆改为目录＋阅读区，目录头部承载标题和计数，阅读区标题、工具条、标签页合为一个头部，正文 72ch 居中。
- 接入页把来源表与“自动接入状态”合并为一张表，每行同时给出采集与 hook 状态，异常原因在行内显示。
- 设置页每段为说明列＋卡片，保存放在卡片底栏；有未保存修改时提示并升为主按钮。预算加单位与范围提示。

## 文件夹选择

- 新增 `POST /api/v1/pick`：由本机服务打开系统原生选择框（macOS osascript、Windows PowerShell、Linux zenity/kdialog），参数经 argv 与环境变量传递，同一时间只允许一个对话框，随请求取消。
- 新增 `GET /api/v1/browse`：列出绝对路径下的目录名（可含文件），不读文件内容。两者都经过现有凭据与 Host/Origin 校验。
- 前端 PathField 统一用于记忆位置迁移与三个来源路径（OpenCode 为文件）。原生框不可用时打开应用内 FolderBrowser，支持键盘、隐藏项目开关和路径分段跳转。迁移前展示“旧位置 → 新位置”。

## 阅读细节

- 无意义标题（原生 id、包装标签、“工具结果：”、Markdown 链接）在显示层清洗，无标题时显示“未命名的 X 会话 · 时间”，原标题保留在 title 属性。
- 工具输出（含 Claude Code 以用户回合保存的工具结果）默认折叠为一行，展开为等宽块。
- 加入 remark-gfm 4.0.1（精确版本），表格、任务列表正常渲染；第三方声明已追加 18 个依赖。
- 目录时间改为“14:02 / 昨天 / 10月3日”。

## 代码组织

`main.tsx` 从 2072 行拆为 api / ui / path-picker / sessions / reader / memories / sources / settings / forget；样式从单个 2423 行文件拆为 `styles/` 下 base、controls、shell、reading、pages、responsive，所有圆角和颜色引用 token。

# 界面细节修整 · 2026-10-15

沿用“档案阅读室”，本轮只处理控件、状态、对齐和导航交互。

## 共用规范

可执行 token 在 `web/src/style.css` 的 `:root`；共用控件在 `web/src/ui.tsx`。现有 DESIGN.md 与 sidecar 已合并本轮已确认的尺寸与行为。

| 项目 | 约定 |
|---|---|
| 常规控件 | 高度 40px，圆角 7px；图标操作 32px，常规图标 16px |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px |
| 键盘焦点 | 2px 轮廓，偏移 2px；复合选择器与搜索框覆盖整个外框 |
| 状态切换 | 140ms |
| 面板、导航 | 240ms，cubic-bezier(0.16, 1, 0.3, 1) |
| 加载 | 900ms 旋转；骨架渐变透明度；尊重减少动态效果 |
| 禁用 | 固定浅色背景及可读文字，不降低整个按钮透明度 |

`SelectField` 保留原生选择器的键盘、输入定位与移动端系统面板，自行统一收起态的边框和 Lucide 箭头。`AsyncButton` 保留按钮原宽度，等待期间禁用并显示状态；`Disclosure` 管理展开、收起、箭头与隐藏内容 inert；`CopyButton` 提供复制成功与失败反馈；`LoadingIndicator` 提供读取状态。

## 已修正

- 迁移表单改为标签在上、输入与按钮底边对齐；中窄屏纵向排列，不再使用默认内联排版。
- 长路径可以换行，复制图标保持位置；展开区域为焦点环保留边距。
- 四个选择器共用箭头、边框、尺寸与焦点。接续菜单支持方向键、Escape、点击外部关闭及焦点返回。
- 搜索读取期间显示加载状态，尚无结果时显示骨架，不提前显示“没有找到匹配”。原文初次读取同样有骨架动画。
- 保存、扫描、修复、校验、重建及迁移操作有忙碌反馈，阻止重复点击。导入期间保留持续状态。
- 桌面导航可收为 72px 图标轨道，并在当前浏览器保留偏好；移动端抽屉具有遮罩、关闭按钮、背景 inert、焦点限制和 Escape 返回。
- 抽屉层级高于短暂提示；减少动态效果时关闭过渡和旋转。
- 归档刷新不再覆盖未保存的来源路径和上下文预算；设置读取失败时禁用保存，防止空配置覆盖。

## 验证

在隔离的本地档案中用真实 Chromium 完成两轮有边界的检查，含桌面、平板、手机、鼠标和键盘。延迟请求及失败响应由浏览器测试模拟，未修改用户实际来源设置、记忆位置或预算。

- 1440px 下输入与按钮均为 40px，底边误差 0px，标签间距 8px。
- 保存按钮忙碌前后均为 98px，仅发起一次请求。
- 选择器键盘选择成功，焦点外框 2px。
- 320 / 390 / 720 / 960 / 1440px 检查无页面横向溢出。
- 侧栏展开中间状态与 72px 终态正确；一次 550ms 本机采样 67 帧，最大帧间隔 9.4ms。这不是其他硬件的帧率保证。
- 移动端抽屉 Tab 未逃出导航，Escape 后焦点回到展开按钮；背景和关闭导航的 inert 正确。
- 复制进入剪贴板并显示成功状态；隐藏内容的焦点环未被裁切。
- 设置 503 模拟响应下，两个保存入口均禁用；恢复正常读取后继续使用。
- 减少动态效果时，侧栏过渡时长为 0s。

原始验证结果：[ui-details-verification.json](ui-details-verification.json)。截图在 `output/playwright/details-*.png`。

机械检测仅运行一次，报告一处布局过渡警告：工作区的 `margin-left`。这是一项明确限定的例外：桌面侧栏收起需要实际让出阅读宽度，因此只在用户主动收放导航时使用 240ms 的侧栏 width / 工作区 margin-left 过渡。其余控件不采用宽高过渡；移动端只移动抽屉。未以再次扫描清除这项警告，相关本机采样如上。
