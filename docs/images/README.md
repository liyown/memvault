# README hero

The README uses [`hero.jpg`](hero.jpg), a 2:1 banner generated with the built-in
imagegen tool. It depicts conversation cards being collected into a forest-green
archive case, on warm ivory paper, matching the project's archival reading-room
design direction.

The image contains the wordmark **Memvault** and the existing project copy
**Your conversations belong to you.** It is intended for the full-width banner
at the top of the root README, not the documentation site's separate illustration.

The original generated PNG is preserved in the local generation library. The
project copy is a JPEG optimized for GitHub loading. The exact generation prompt
is stored in [`hero.prompt.md`](hero.prompt.md).
